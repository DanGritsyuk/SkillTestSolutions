# # NexusStock Warehouse Management

Приложение для упрощённой автоматизации работы склада: управление справочниками, приходами, отгрузками и балансом.

---

## Основные возможности

- **Справочники**  
  - Ресурсы  
  - Единицы измерения  
  - Клиенты  
- **Документы**  
  - Поступления (создание/редактирование/удаление)  
  - Отгрузки (создание, подписание, отзыв)  
- **Баланс на складе**  
  - Автоматическое суммирование по ресурсу и единице измерения  
  - Авто-обновление при операциях прихода и при подписании/отзыве отгрузок  
- **Бизнес-правила**  
  - Уникальность по наименованию/номеру  
  - Запрет удаления используемых сущностей — переход в архив  
  - Нельзя подписать отгрузку, если ресурсов недостаточно  
  - При изменении количества в документах баланс всегда остаётся валидным  
- **Фильтрация на сервере**  
  - На странице «Склад» — фильтры по ресурсам и единицам  
  - На страницах «Поступления» и «Отгрузки» — по дате, номеру, ресурсам и единицам (multi-select)  
- **Авто-создание БД**  
  - Приложение само создаёт и мигрирует базу при первом запуске

---

## Технологический стек

- **Backend**: ASP.NET Core WebAPI, C#  
- **Frontend**: ASP.NET Core Razor Pages  
- **ORM**: Entity Framework Core  
- **База данных**: MS SQL Server / PostgreSQL (конфигурируется в `appsettings.json`)
