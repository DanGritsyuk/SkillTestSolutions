# KaruselContestParser

Программа для автоматического парсинга конкурса на сайте телеканала **Карусель** и отображения списка участников, их мест и информации о конкретной работе.

## 📌 Возможности
- Загрузка списка участников конкурса с официального сайта.
- Определение **топ-10 участников** по количеству голосов.
- Поиск информации о конкретной работе по её ссылке.
- Вывод статистики в консоль с расширенным форматированием.
- Обработка ошибок и аккуратное завершение работы.

## 🔧 Настройка
В файле `Program.cs` задаётся константа:
```csharp
const string targetWorkUrl = "https://www.karusel-tv.ru/contest/fiksiki2025/photo/1115";
```
Измени её, чтобы программа выводила информацию по другой работе.
