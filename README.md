# Сопроводительное письмо к проекту CompanyDirectory

## О проекте
**CompanyDirectory** - это веб-приложение для управления сотрудниками компании, разработанное в соответствии с техническим заданием. Проект демонстрирует навыки full-stack разработки с использованием современного стека технологий.

## Ключевые особенности реализации
### Backend (ASP.NET Core 8)
- RESTful API с контроллерами Employees и Departments
- Асинхронные методы работы с базой данных
- Логирование операций через ILogger
- Подробная обработка ошибок

### Frontend (Angular 20)
- Гибкая модульная структура проекта
- Реализованы два основных раздела:
  - Статичная страница "О компании"
  - Интерактивная таблица сотрудников с CRUD-операциями
- Использование Angular Material для UI
- Адаптивный дизайн

### База данных (MS SQL)
- Нормализованная структура (отделы ↔ сотрудники)
- Скрипты для основных операций из ТЗ
